# Приёмка UI15: сравнение совместных проверок

17 октября 2026. Продуктовый код подготовлен DeepSeek через OpenRouter,
тесты и независимое ревью — Gemini через тот же адаптер с отдельным ключом
разработки. Оркестратор составлял задания, проверял и применял точные ответы,
выполнял проверки и оформлял документацию. Встроенные Codex-агенты не использовались.

## Реализовано

В отчёте «Файлы + тесты» добавлена кнопка «Сравнить с предыдущей проверкой».
В истории можно выбрать произвольную пару одного проекта. Направление явно
base → target; обратная хронология разрешена. Быстрая кнопка выбирает ближайший
строго более старый claim среди последних 20 ссылок, включая pending/incomplete.
Ошибка чтения истории отличается от отсутствия предыдущей ссылки.

Новый read-only GET возвращает вычисленное сравнение только после повторной
проверки сохранённых составляющих и их хешей. При полной сопоставимой паре видны
новые/исчезнувшие замечания, число оставшихся, изменения статусов инструментов
и совпадение снимка. Регрессии инструментов и новые ошибки идут первыми.
Сдвиг строки/переименование не объявляются исправлением. Сравниваются агрегированные
статусы инструментов, не отдельные тесты и не количество тестовых ошибок.

Pending, неполнота, отсутствие статического отчёта, смена профиля, окружения,
образа или версии правил отключают добавленные/исчезнувшие счётчики. Причины
показываются явно. Сохраняются ссылки на оба исходных отчёта. Сравнение не пишет
историю, не читает текущие исходники, не запускает Docker, AI или новую проверку.
Сохранённые DTO и F06-аудит не менялись.

## Выполненные проверки

- Offline unit/contract/safety: **1315 passed, 3 skipped** за 113.71 секунды,
  .local/ui15-offline.xml. Исключены integration, llm_live, kind_live, opa_live,
  runner_live. Доступность внешних сервисов этот набор не подтверждает.
- Новые целевые core/HTTP сценарии: **25 passed, 104 deselected**,
  .local/ui15-targeted.xml. Проверены кратность/координаты замечаний, статусы
  инструментов, same_snapshot, reverse chronology, все причины отказа, подмена
  хеша, pending, жизненный цикл репозитория, session/Host, точный маршрут,
  разные проекты/одинаковые ID, снятая регистрация и неизменность файлов при GET.
- Node UI: **26 passed**. Новые пять сценариев покрывают сопоставимую пару,
  регрессии первыми, вывод HTML-подобных строк как текста, неполные/различающиеся
  результаты без ложных счётчиков, выбранные ID и GET-only, поиск предыдущего
  включая pending, пустую/повреждённую историю и отбрасывание позднего ответа.
- Ruff, format check изменённых Python-файлов, strict mypy **129 source files**,
  **22 import contracts**, node --check и git diff --check прошли.
- Offline sdist → wheel в .local/ui15-dist. comparison.py, app.js, index.html
  и style.css из wheel побайтово совпали с исходниками.
- Финальное независимое статическое ревью Gemini: **accept**, замечаний нет.
  Ревью модели само по себе не является запуском тестов; команды выше выполнены
  оркестратором на реальных файлах.

## Происхождение изменений

Ответы моделей проверялись как недоверенные: разрешённые пути и точные совпадения
замен. Неверные типы image_id/constant и необязательный fail-open helper в одном
ответе DeepSeek не применялись; минимальная корректировка запрошена у автора.
Путь app.js в UI-ответе сопоставлен с единственным заранее разрешённым файлом.
Две одинаковые тестовые замены из ответа Gemini применены по одному разу каждая,
с проверкой двух исходных совпадений и одного оставшегося после первой замены.
Некорректные API/фикстуры и ожидания тестов возвращались Gemini по фактическим
ошибкам. Оркестратор не писал продуктовый код или тесты вручную.
Материалы заданий и ответов находятся вне Git в work/agent-tasks/ui15.

Локальная история остаётся неподписанной; согласованная подмена администратором
всех файлов не предотвращается. Публикация в интернет и push в GitHub в эту
приёмку не входят.
