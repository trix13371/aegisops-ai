# UI22: исправления по аудиту плана

19 октября 2026. Закрыты первичные замечания из
[сверки Stage −1](docs/PLAN-AUDIT-2026-10-19.md): среда БД, карта Python-импортов,
распределение ограниченного контекста, UI-набор в CI и область ранних запретов.
Решение: [ADR-038](docs/decisions/ADR-038-audit-followup-and-context-selection.md).

## Среда и живые проверки

Запущен существующий `aegisops-prototype-s001-postgres-1` с прежним volume;
БД не пересоздавалась. Health=healthy, doctor synthetic — OK,
`alembic check` — No new upgrade operations detected.

Первая проверка local-kind отказала на старом reader. Штатный refresh-reader
выпустил новый read-only token с прежним запрошенным TTL 10 минут; права не
расширялись. Doctor local-kind после обновления — OK, marker проверен.
Это ограниченная живая приёмка в момент прогона, не бессрочный доступ.

- Реальная БД и full-pipeline без kind: **30 passed, 1 deselected**, 4.86 s.
- Реальный kind/RBAC и local-kind full-pipeline: **20 passed, 7 deselected**, 3.91 s.
- Новые миграции, переинициализация ролей и изменение kill switch не требовались.
- БД-тесты записывают свою тестовую историю. Проверка подписанного checkpoint
  для новых строк в этом шаге не выполнялась.

## Регрессия изменений

- Общий итоговый набор с PostgreSQL: **1561 passed, 4 skipped, 69 deselected**,
  176.22 s. Включены integration/E2E; live-треки исключены, kind принят отдельно.
- Новый набор selector/imports/CI/recommendation: **7 тестов**. Реальные временные
  пакеты, ImportFrom/alias/star, отсутствие ложных путей псевдонимов, пределы

  независимые курсоры папок, приоритет обычного модуля над __init__, роли,
  каталог >200, карта >80 и несвязанный тест перед запасными модулями.
- Целевой прогон code-context/recommendation/workbench/capture: **41 passed,
  1 skipped**. Symlink-пропуск не засчитан как проверенный сценарий ОС.
- UI MockDOM: **47 passed**; JS не менялся, consent/preview-переходы сохранены.
- Ruff lint/format, mypy (**147 source files**), import-linter (**25 contracts**),
  **57 schemas**, package assets и node --check — успешно.
- uv build --offline создал wheel/sdist; context.py, source.py и selection.py
  в wheel сверены побайтно с рабочими файлами.
- Настройка GitHub Actions содержит полный SHA setup-node, Node 22 и запуск
  действующего UI-набора. YAML проверен тестом, удалённый workflow не запускался.
- Gitleaks staged: **no leaks found**. Ложное срабатывание на литерал фейкового
  токена в тестовой .env-фикстуре устранено генерацией канарейки во время теста;
  правила сканера не менялись. После этого новый набор повторён: **7 passed**.

Итог общего прогона с PostgreSQL сохранён отдельно в
`.local/ui22-regression-final.xml` и машинной сводке

## Авторство и оставшиеся границы

Продуктовый код и workflow подготовлены DeepSeek через отдельное API разработки;
тесты и независимое ревью — Gemini. Итоговые ревью: findings=[], verdict=pass.
Оркестратор проверял точные замены, применял ответы, запускал проверки и UI.
Неполный ответ не применялся. Кандидаты с выдуманным старым блоком, несуществующим
helper, ложными alias-путями, общим курсором роли и LIFO вместо BFS исправлены
автором до применения. Ошибки API/синтаксиса и слабые проверки в тестовых
кандидатах возвращены Gemini и исправлены до успешного прогона.

API-ключи нейропомощников не менялись; ключи/.env/телеметрия/пользовательские
исходники не передавались моделям разработки. В проверках UI22 платные
runtime-вызовы и запуск пользовательского кода в runner не выполнялись.
OPA mTLS, удалённый CI, качество настоящей модели, чистая ОС и публичный хостинг
не принимались заново. Расширение AI benchmark остаётся следующим отдельным шагом.
Публикация в GitHub не выполнялась.
