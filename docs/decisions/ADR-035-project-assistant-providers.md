# ADR-035: выбор сервиса нейропомощника для проектов

Статус: принято, локальный прототип. 19 октября 2026.

Пользователь скачавшего проект может подключить собственный ключ OpenRouter,
DeepSeek, Google Gemini или OpenAI. Основной интерфейс использует название
«нейропомощник»; реальные названия сервисов видны в настройках подключения.

## Решение

Закрытый каталог `aegisops.assistant.models` задаёт ровно четыре пары:
openrouter/deepseek/deepseek-v4.1-flash, deepseek/deepseek-flash,
gemini/gemini-3.8-flash и openai/gpt-5.4-mini. Произвольных endpoint, моделей,
инструментов, повторов и fallback между сервисами нет. Прямые адаптеры используют
проверенный TLS, фиксированные host/path, один POST, ограниченный ответ и
безопасные сообщения ошибки. Ключ Gemini передаётся заголовком, не query string.

Это расширение шести режимов: project_ai, project_review_ai, project_check_ai,
project_code_ai, project_code_fix, project_code_evaluation. Старые согласия,
предпросмотры, started-claims и проверки сохранённых доказательств остаются.
Сводки ограничены прежними 16 КиБ запроса / 1600 выходными токенами; разбор
исходников — 64 КиБ запроса / 2800 токенами. Ответ ограничен 64 КиБ, сетевой
таймер — 30 секунд. DNS может зависеть от ограничений ОС. Ни настройки сервиса,
ни ответ модели не разрешают исполнение кода или применение исправлений.

Мастер Connect-Neuroassistant.cmd читает ключ в скрытом поле. Только после
metadata GET он создаёт DPAPI-файл текущего Windows-пользователя вне checkout:
`../../work/aegisops-runtime-credentials/{provider}.dpapi`. Существующий файл
используется повторно, не перезаписывается. Смена активного provider/model
в `assistant.json` атомарна; файл не содержит ключа. Ошибка preflight не меняет
прежнее подключение. Проверяются reparse points и предки путей; доступ к
каталогу ограничивается текущим пользователем. Это не изоляция от того же
доверенного OS-пользователя и не production vault.

`GET /api/assistant` доступен только текущей локальной сессии, отдаёт каталог,
выбор и наличие файла ключа; он не расшифровывает ключ и не вызывает модель.
Browser API записи ключей или настроек нет. Прямые сервисы не дают прежний
универсальный контракт проверки денежного лимита: интерфейс явно указывает,
что бюджет задаётся на стороне аккаунта. Для OpenRouter прежний общий лимит
ключа до $5 без сброса и остаток от $0.10 проверяются перед запуском.

## Привязка попытки и совместимость

Перед принятием новой задачи проверяется активный выбор. В общем job-lock,
после claim и до worker, сохраняется O_EXCL-привязка provider/model:
`.local/assistant-attempts/{mode}/{UUID}.json`. Мастер может менять выбор для
следующих задач; уже принятая задача читает только свою привязку. Wrapper
повторно сверяет её перед дочерним процессом, передаёт только выбранный ключ
через окружение и запускает фиксированный worker из проектной .venv.

Отсутствие assistant.json сохраняет прежнее поведение и старый launcher.
Неполный, неизвестный или повреждённый выбор отклоняется. Старые попытки без
привязки всегда разрешаются в legacy-пару независимо от нового активного выбора.
Строка model сохраняется и при успехе, и при штатно записанном сбое. Старые JSON
без model читаются с прежним значением. Для legacy LabResult поле model исключено
из digest, чтобы не сломать уже сохранённые verification claims UI17.

Маршрутизация incident/cluster, политики F01/F09, L0 CLI, OPA и разрешения
передачи телеметрии не расширяются. Для будущего интернет-размещения потребуется
отдельное серверное хранилище секретов и изоляция пользователей; этот ADR их не
реализует.

## Контракты внешних API

Проверены официальные документы 19 октября 2026:

- [DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)
  и [модели](https://api-docs.deepseek.com/quick_start/pricing/): deepseek-flash,
  thinking disabled, JSON object.
- [Gemini generateContent](https://ai.google.dev/api/generate-content)
  и [Gemini 3.8 Flash](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash):
  native REST, JSON MIME, thinking LOW; MINIMAL здесь не используется.
- [OpenAI Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)
  и [GPT-5.4 mini](https://developers.openai.com/api/docs/models/gpt-5.4-mini):
  max_completion_tokens, reasoning_effort none, store false, JSON object.

Реальная доступность модели зависит от аккаунта, региона и прав ключа. Проверка
метаданных не доказывает успешную генерацию или корректность будущего ответа.
Прямые адаптеры приняты офлайн с подменой HTTP; live-генерация прямыми сервисами
в этой среде не выполнялась. Фактическая приёмка — VERIFICATION-UI19.md.
