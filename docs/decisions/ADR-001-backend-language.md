# ADR-001: Python для локального прототипа

Статус: принято пользователем; оформлено 14 октября 2026.

Основание: редакция 2.1 Stage −1, решения от 10 октября 2026.

Используем Python 3.12+, uv и uv.lock, Pydantic v2, Typer, SQLAlchemy 2,
Alembic и psycopg. Контракты будущей задачи S0-02 экспортируются в JSON Schema.
Go и TypeScript рассматривались ранее; для этого прототипа выбран Python.
Решение не задаёт язык будущего production Cluster Agent.

Первый срез — CLI и среда разработки. LLM не управляет конвейером;
все обязательные тесты работают без платного API.
