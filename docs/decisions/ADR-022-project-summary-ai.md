# ADR-022: явный нейросетевой разбор сводки локального отчёта

16 октября 2026. Пользователь запросил нейросеть через интерфейс проекта.
Первый режим объясняет существующие статические замечания; он не сканирует
исходники моделью и не расширяет полномочия модели до исполнителя.

Введён отдельный профиль разрешённой передачи `project-summary-v1`. Это новая
граница для производной сводки локальных проверок, а не понижение класса
исходников или выдача реальных данных за synthetic. Исходный проект и отчёт
остаются локальными. Проекция строится заново из проверенного DTO по закрытой
схеме: фиксированный профиль и версия правил, enum статуса, ограниченные числа
files_checked/skipped, enum code/severity и количество замечаний каждого типа.
Сырых строк, имён, путей, координат, timestamps, UUID, stack labels и значений
конфигурации во входе модели нет. Это структурный allowlist, не regex-DLP.
Сам факт категорий/количеств тоже является раскрытием сводки: перед отправкой
оператор видит точный JSON и даёт отдельное согласие на платный запрос.

Класс исходной Kubernetes-телеметрии и F01/local-data-v1 не меняются. Новая
проекция не передаётся в старый AnalysisEngine/LLMRequest; не маркируется как
public synthetic. Model transport получает только Summary, повторно проверяет
DTO и строит фиксированные сообщения. 19 import-контрактов запрещают обычному
scanner импортировать project_ai и отделяют чистую проекцию/хранилище от сети,
ключей, DB/config, Kubernetes и incident pipeline.

HTTP API сохраняет loopback, session, точные Host/Origin, CSP и bounded JSON.
GET /api/project-ai/<report UUID> возвращает проекцию/сохранённое состояние,
не читает ключ и не вызывает провайдера. POST /api/jobs принимает только
mode=project_ai, report_id и consent=project-summary-v1; endpoint, модель,
произвольный payload/ключ/команда из браузера отвергаются. Требуется текущая
регистрация проекта; существующий job-lock сериализует запуск и удаление.

До запуска дочернего процесса создаётся O_EXCL claim, связанный с UUID и SHA256
канонического DTO отчёта. Повтор того же отчёта отвергается, в том числе после
перезапуска. Worker проверяет hash/проекцию и создаёт отдельный O_EXCL started
до обращения к модели. Сбой до/после запроса не запускает retry. Старые попытки
не удаляются автоматически. Для осознанной новой попытки нужен новый статический
отчёт. Host читает результат с диска; stdout не является доказательством ответа.
Завершённый результат, уже сохранённый worker, не заменяется ошибкой host.
Если ошибка сохранена раньше позднего ответа, состояние остаётся failed.
Pending после падения сохраняет неопределённость; это не успешный анализ.

Внешний процесс запускается только операторским script-host вне src. Фиксированный
PowerShell launcher использует прежний отдельный runtime DPAPI-ключ и preflight
лимита (положительный общий <=$5, без reset, remaining >=$0.10). Development key,
generic ключ родителя, PostgreSQL/Kubernetes credentials не наследуются.
PSMODULEPATH пересоздаётся Windows PowerShell: наследование пути PowerShell 7
ломало Security module autoload в фоновом Python, ошибка найдена и исправлена
при реальной проверке. Ключ не выводится, не передаётся в argv или браузер.

Фиксирован OpenRouter HTTPS endpoint и модель deepseek/deepseek-v4.1-flash.
Используется JSON mode с локальной строгой валидацией ответа, <=5 советов с
уникальными кодами из отправленных категорий, enum приоритетов, bounded text.
Tools/refusal/неожиданный model/обрезанный finish_reason отвергаются. Текст
выводится через textContent. Нет tools/plugins, исполнения команд, автоматической
смены модели/провайдера или повторов. Вход <=16 KiB, ответ <=64 KiB, выход
<=1600 токенов; socket timeout/deadline 30s, host subprocess timeout 80s.
TLS проверяется, в том числе через допустимый HTTP CONNECT proxy; redirect не
следуется. Preflight и транспорт не выводят исключения, HTTP body или headers.
Семантика API: [официальная документация OpenRouter](https://openrouter.ai/docs/api_reference/overview).

Хранение: .local/project-ai/<report UUID>/{claim,started,result}.json, exclusive
запись + fsync/readback, bounded typed reads, проверка связи/hash/кодов.
Это локальная история без криптографической подписи, вне F06 audit_runs. Сохраняются
допущения UI02 о доверенном OS user/filesystem и ограничениях файловых гонок.
Не обещаются изоляция от владельца хоста, zero-retention у провайдера, DLP для
произвольного текста или гарантированное качество рекомендаций. Сохранённый
ответ модели не изменяет статус, содержимое или область статической проверки.
