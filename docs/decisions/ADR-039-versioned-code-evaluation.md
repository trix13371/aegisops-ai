# ADR-039: версионированная оценка разбора кода

Статус: принято. Дата: 19 октября 2026. Шаг UI23.

## Причина

Прежние три Python-примера не показывали поведение на JavaScript/TypeScript,
чистом коде и связях между файлами. Изменение существующего набора сломало бы
проверку хешей сохранённых отчётов и увеличило бы число запросов по старому согласию.

## Решение

Сохранить `synthetic-line-overlap-v1`, его три примера, метрики и класс результата.
Добавить отдельный `synthetic-file-overlap-v2`: девять неизменяемых примеров,
по три на язык, пять случаев с ошибкой, два чистых и два с недоверенными
инструкциями внутри корректного кода. Два случая содержат несколько файлов.
Код примеров приложение не исполняет. Метки предварительные; независимое ревью
не превращает их в подтверждённый эталон качества модели.

Версия фиксируется в claim; отсутствие поля означает v1. Каждое чтение проверяет
хеш именно этой версии. Результаты имеют разные строгие DTO и лимиты чтения:
192 KiB для v1 и 512 KiB для v2. Смешанная история не пересчитывает старые отчёты.
Хеш v2 включает весь набор, содержимое файлов, пути и предварительные метки.

`GET /api/project-code-evaluation` остаётся v1; отдельный
`GET /api/project-code-evaluation-v2` возвращает новый каталог. Оба маршрута
требуют прежнюю локальную сессию и проверку Host. Чтение не создаёт claim.
`POST /api/jobs` принимает прежний режим `project_code_evaluation` и точное
согласие `project-code-evaluation-v1` либо `project-code-evaluation-v2`.
Произвольные наборы, пути, модели и дополнительные поля не принимаются.

V2 ограничен девятью последовательными вызовами, каждый до 2800 выходных токенов.
Общий предел 25200 не является ценой в долларах; входные токены также оплачиваются.
Модель и провайдер фиксируются существующей привязкой задания. Ключи, режимы
провайдеров и credential store не меняются. В модель попадают только синтетические
содержимое/язык/идентификатор файла через прежний wire payload; ожидаемые метки
и пояснения не отправляются. На первом сбое запросы прекращаются без retry.
Внешний timeout v2 — 360 секунд; v1 остаётся 160. Общая блокировка заданий сохранена.

После прежней проверки доказательств в цитатах совпадение требует того же file_id,
пересечения строк и ожидаемой категории. Максимальное паросочетание даёт каждой
находке и каждой ожидаемой ошибке максимум одно совпадение; дубли становятся FP.
Отсутствие ответа — отсутствие покрытия, а не придуманная пропущенная ошибка.
При частичном прогоне precision/recall отсутствуют в общей и языковых сводках.
TP/FP/FN и покрытие относятся к полученным ответам. Для clean/injection отдельно
считаются случаи с ложными срабатываниями. Токены хранятся для принятых ответов;
расход невалидного или оборванного вызова может отсутствовать в отчёте.

## Проверка и ограничения

Синтетические ответы проверяют механизм подсчёта, а не настоящую точность модели.
Оплачиваемая runtime-оценка запускается только после отдельного согласия в UI.
Набор маленький, не покрывает весь язык, безопасность и понимание архитектуры;
пересечение строк не доказывает семантическую правильность замечания.
UI показывает содержимое и метки как текст; старые отчёты доступны в исходном виде.
Подробные результаты выполненных проверок: [UI23](../../VERIFICATION-UI23.md).
