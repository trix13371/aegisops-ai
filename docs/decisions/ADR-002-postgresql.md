# ADR-002: локальный PostgreSQL

Статус: принято согласно техническому плану; 14 октября 2026.

Используем PostgreSQL 17 в отдельном Docker Compose-проекте. Порт публикуется
только на 127.0.0.1. SQLite из прежней демонстрации сюда не переносится.
SQLAlchemy описывает таблицу audit_runs; Alembic управляет миграциями.

Разделены bootstrap-администратор, роль-владелец миграций и роль приложения.
Приложение имеет только SELECT/INSERT на audit_runs и не может UPDATE/DELETE,
TRUNCATE или менять схему. Пароли генерируются локально и не входят в Git.

Обычная таблица PostgreSQL не является audit-grade: нет подписей, WORM,
внешней фиксации и защиты от администратора БД. Hash-chain не входит в S0-01.
