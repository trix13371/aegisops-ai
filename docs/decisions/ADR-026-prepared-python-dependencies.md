# ADR-026: подготовленные Python-зависимости

Принято 16 октября 2026. Локальный функционал, без подготовки публичного хостинга.

Базовый runner не содержит библиотек проекта. Ошибка импорта до сбора тестов
не означает дефект проверяемой логики. Добавляем выбор закрытого environment ID:
minimal и python-data-v1, сохраняя профиль исполнения python-checks-v1.

minimal содержит прежние инструменты. python-data-v1 добавляет Pydantic 2.14.1,
PyYAML 6.0.3 и их закреплённые транзитивные зависимости. Операторский requirements
скопирован из текущего uv.lock; каждый пакет закреплён версией и wheel SHA256.
pip --only-binary=:all: --require-hashes исключает сборку sdist и установку
незакреплённых транзитивных пакетов. Это не автоматическое обновление lock.

Подготовка — явный operator CLI, который собирает только доверенный ограниченный
контекст runner/python-v1. Файлы, Dockerfile и requirements проверяемого проекта
не используются. Сеть допустима только для сборки собственного образа; секреты
и пользовательские исходники в build context отсутствуют. API не собирает образы,
не принимает список пакетов, команды или параметры pip/Docker.

Каждое окружение имеет отдельный локальный image pin; context hash включает
environment ID, оба requirements, Dockerfile и entry.py. Запуск использует
immutable image ID с прежней проверкой изоляции и cleanup. Claim/RunResult
содержат environment; чтение отвергает несовпадение. Старые записи default minimal.
Разные environment/image ID исключают автоматический вывод об исправлении кода.

Подсказка о ModuleNotFoundError извлекается из ограниченного сохранённого pytest
вывода (до 20 уникальных имён, 128 символов, синтаксис Python import). Это
недоверенное сообщение; оно не запускает resolver, установку или запрос нейросети.
Импорт может быть частью проекта, а имя distribution может отличаться.

Новые произвольные зависимости, editable install, project plugins, lock resolver,
JS/TS и контейнеры с сетью остаются за рамками этого среза. Для новых окружений
нужен отдельный проверяемый операторский preset. Прежние доверительные допущения
Docker/user/filesystem и ограничения аттестации тестов сохраняются.
