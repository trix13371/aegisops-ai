# ADR-019: локальная панель оператора в браузере

Принято 15 октября 2026. UI01 — визуальная оболочка существующего L0, без
расширения автономности. Новые зависимости и публичный сетевой API не нужны.

`Start-AegisOps.cmd` → PowerShell → pythonw открывает браузер и переиспользует
собственный локальный host на `127.0.0.1:8765`. При занятом неизвестным сервисом
порте launcher отказывает, не останавливая посторонний процесс. HTML/CSS/JS/SVG
хранятся локально, без CDN, внешних шрифтов, аналитики или отдельной сборки Node.
Весь динамический текст из аудита выводится через textContent.

Host находится в operator scripts, вне application capabilities: только он
может запускать фиксированные CLI-процессы. `src/aegisops/dashboard` содержит
только проекцию сохранённого AuditRecord, без raw context и provider metadata;
новый import-контракт запрещает ей транспорт, SDK, signer и конфигурацию.
Это 16-й import-контракт, прежние границы collector/control сохранены.

Короткая capability создаётся случайно при старте, хранится в игнорируемом
локальном файле и через однократный переход launcher обменивается на HttpOnly,
SameSite=Strict session cookie; URL затем очищается redirect. Capability
действует до остановки host, bootstrap-ссылка может повторно использоваться
локальным launcher в пределах этой сессии. HTTP обслуживается только loopback;
Secure cookie на нём не используется. URL/cookie/детали ошибок не логируются.
Каждый запрос требует точный Host, API требует сессию, POST также точный Origin.
CORS отсутствует, framing запрещён, CSP допускает только собственные ресурсы.

POST принимает строго ограниченный JSON ≤1024 байт, без duplicate keys. Доступны
только запуск local_kind, три фиксированных учебных сценария и остановка idle UI.
Один job за раз, без автоматического повторения POST или незавершённого пакета.
Collector не получает DB/LLM/kube environment; Control Plane получает только
app DB URL. Режим OpenRouter, произвольный endpoint, shell, путь, reset/retry claim,
выпуск ключа, редактирование политики и resume controls недоступны в API.

Local-kind использует обновление существующего reader, отдельный collector и
F09 consume. Учебные сценарии используют CLI run с `--llm none --authorization opa`.
Результат JSON валидируется существующим DeliveryResult/PipelineResult до показа.
Ненулевой exit с валидным blocked-результатом отображается как блокировка, а не
как потеря связи. При ошибке stdout/stderr дочерних процессов не передаются браузеру.

История — bounded выборка до 25 метаданных с проверкой/санитизацией каждого
AuditRecord существующим reader; невалидные строки пропускаются с видимым счётчиком.
Метрики явно относятся к этой выборке, не являются общей статистикой или quality.
История содержит и автоматические тестовые данные той же локальной БД. Health
сервисов кешируется до 15 секунд и не заменяет обязательные проверки в pipeline.

Ограничения: stdlib HTTP host предназначен для локальной разработки на доверенном
хосте, не production/многопользовательского сервиса. Доверены OS user, браузер,
локальные файлы и operator scripts. Capability не защищает от захвата этого
пользователя; временная bootstrap-ссылка доступна локальному браузеру. Job state
в памяти теряется при остановке процесса; durable источники — аудит и F09 spool.
Автоматического восстановления нет. Закрытие вкладки не останавливает backend;
явная остановка UI отвергается во время активной проверки. Режим остаётся L0.
