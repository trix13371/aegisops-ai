# ADR-037: локальный подбор стартовых файлов для разбора кода

Статус: принято. 19 октября 2026.

До разбора кода пользователь выбирает файлы вручную. Подбор связанных файлов
уже существует, но требует исходного выбора. Новый начальный подбор помогает
начать разбор и показывает основания выбора до подготовки предпросмотра.

`project_code.context.recommend_review` один раз вызывает существующий build_map.
Карта теперь сохраняет размер UTF-8 и SHA256 успешно захваченного файла вместе
с прежними связями и ролями. Исходное содержимое в карте и ответе отсутствует.
Недоступные файлы получают bytes=0, sha256=null и не попадают в рекомендации.
Файл с ошибкой синтаксиса может быть предложен, если безопасный захват успешен;
карта при этом остаётся неполной. Подбор не исполняет код и не использует модель.

Сохраняются ограничения карты: каталог до 200 имён, первые 80 кандидатов,
до 256 КиБ текста, включённого в разбор, и проверка пятисекундного бюджета.
Это не обещание завершить весь обход папки за пять секунд: каталог строится
раньше, текущая операция чтения не прерывается по таймеру. Действуют прежние
ограничения безопасного capture, в том числе отказы для ссылок и известных
признаков секретов. Это эвристические защиты, а не гарантия очистки кода.

Ранжирование детерминировано: роль, число входящих импортов, путь без учёта
регистра и исходный путь. Первая точка входа, либо наиболее используемый модуль,
становится опорным файлом. Далее добавляются импортированный модуль, тест по
связи/имени/обратному импорту и конфигурация, когда позволяет размер. Остаток
заполняется кодом, тестами, конфигурацией и документацией в том же порядке.
Дубликаты путей без учёта регистра исключаются. Один файл — до 12 КиБ,
общий выбор — до 5 файлов и 24 КиБ. Алгоритм жадный: покрытия всех ролей,
оптимального заполнения бюджета и обнаружения всех связей не гарантирует.

GET /api/project-code-recommendation/{UUID} проходит прежние проверки Host
и сессии. Возвращается профиль project-code-selection-v1, массив path/bytes/
sha256/reason, суммарный размер, лимиты, partial и limitations. Маршрут не
создаёт claims, предпросмотры, задачи или записи в рабочей папке. POST отсутствует.
Ошибки неизвестного проекта и повреждённых идентификаторов обрабатываются
прежним фиксированным ответом без раскрытия исключений.

Интерфейс не запрашивает рекомендации при открытии панели. Отдельное нажатие
«Подобрать стартовые файлы» вызывает только GET. Клиент проверяет профиль,
известные пути, дубликаты, размеры, SHA256, лимиты и общий размер. Тексты и
пути отображаются как текстовые узлы. Пока запрос выполняется, выбор заблокирован;
ответ старой закрытой панели не применяется. Неудачный ответ сохраняет ручной выбор.

«Выбрать эти файлы» меняет только текущие отметки. Подготовка предпросмотра
остаётся отдельной операцией и повторно захватывает текущее содержимое.
Показанный при подборе SHA256 не является замороженным согласием на отправку:
пользователь проверяет фактический предпросмотр и отдельно разрешает платный запрос.
Хранение ключей, транспорты, модели и условия будущего хостинга не меняются.
