# ADR-036: экспорт сохранённого разбора и предложения исправления

Статус: принято. 19 октября 2026.

Разбор и предложение должны быть доступны вне панели без повторного обращения
к нейросети. Добавлены Markdown-отчёт и ZIP с патчем, отдельным тестом и
описанием доказательств. Экспорт не применяет патч и не запускает код.

`project_code.export.review_markdown` читает готовый CodeResult через существующий
CodeRepository. Проверяются ID, digest замороженного preview и валидность
замечаний. В Markdown включены исходная модель, даты, хеши и относительные пути,
диапазоны строк, категории, цитаты, объяснения, рекомендации и ограничения.
Полных исходников нет. Отсутствие замечаний не объявляется отсутствием ошибок.

`proposal_zip` использует LabRepository: сохранённый разбор, claim/result
предложения и verification. Повторно проверяются связи и validate_proposal.
Завершённая проверка проходит validate_verification на тех же замороженных
данных; её статус не принимается без проверки хешей и классификации прогонов.
В manifest сохраняется фактическое not_requested, pending, reproduced,
not_reproduced или inconclusive. Это вывод о конкретном тесте, не доказательство
семантической правильности исправления. Логи прогонов в архив не включаются.

ZIP создаётся в памяти. Ровно пять плоских имён: README.md, review.md,
proposal.patch, manifest.json и test_aegis_repro.py либо aegis-repro.test.mjs.
Имена entries не берутся из проекта или ответа модели. Пути внутри patch
проверяются: относительные POSIX, без control characters, drive, backslash,
пустых/dot/dotdot-компонентов. Коллизия фиксированного имени теста отклоняется.
Патч построен прежним proposal_diff, тест сохраняется без изменения байтов.

В manifest версии project-code-export-v1 входят ID/digest preview, модели
разбора и предложения, целевой путь и хеши до/после, verification и SHA256
остальных четырёх entries. Сам manifest себя не хеширует. ZIP_STORED, timestamp
1980 и права обычного файла 0644 дают побайтную воспроизводимость при неизменной
истории. Markdown и каждый entry ограничены 256 КиБ; итоговый ZIP — 1 МиБ.

Тексты модели и пути в Markdown выводятся только внутри fenced code blocks.
Длина fence минимум три backtick и больше любого их непрерывного набора во
входе. Непроверенный текст не дублируется вне блока, не создаёт HTML, ссылок
или внешних изображений при обычном Markdown-rendering.

Маршруты GET /api/project-code-export/{UUID} и /api/project-fix-export/{UUID}
проходят прежние Host/session проверки; POST для них отсутствует. Ответы —
attachment с фиксированным UUID-именем, no-store, nosniff и прежним CSP.
Неполные или повреждённые данные дают фиксированную ошибку без содержимого
credential/log/exception. Кнопки показываются только у завершённых результатов.
Открытие панели не запрашивает export заранее. Новых claims, задач, запросов
модели, записей в папку проекта и временных файлов экспортёр не создаёт.

Модуль добавлен в существующий import contract чистых компонентов code lab.
Публичный хостинг и изоляция владельцев не реализуются этим изменением;
экспорт остаётся в текущей локальной сессии. Содержимое скачанного архива
пользователь передаёт вручную на своё усмотрение.

Дополнительно уточнён старый текст бюджета сводного AI-разбора: общий денежный
потолок прежнего подключения не выдаётся за гарантию для всех прямых сервисов.
Транспорт, хранение ключей и ограничения платных вызовов не менялись.
