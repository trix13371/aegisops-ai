Connect-Neuroassistant.cmd; просмотр состояния — кнопка «Нейропомощник».

## Что проверяют новые границы

Каталог закрыт, несовместимые provider/model отклоняются. Отсутствие config
сохраняет legacy, повреждённый или неполный config отклоняется. Новая попытка
получает O_EXCL-привязку до worker; смена активного подключения её не меняет.
Старая попытка без привязки не обращается к новому активному выбору.

Транспортные тесты подменяют HTTPS и проверяют фиксированные host/path, заголовки
ключей, JSON-параметры, usage/model/finish reason, обрезанные и неверные ответы,
запрет tools/повторов и ограничение размеров. Windows harness использует только
canary-ключи в pytest tmp_path, реальное шифрование DPAPI и фиксированные ответы
метаданных. Он проверяет reuse ключа, сохранение config при ошибке и денежные
ограничения старого подключения. Тесты не обращаются к настоящим credentials.

## Разработка и пределы подтверждения

DeepSeek через отдельный API разработки подготовил продуктовые изменения;
Gemini — тесты и независимое статическое ревью credential/transport границ.
Ревью вернуло findings=[] для обеих частей. Оркестратор проверял точные замены,
применял их, запускал реальные команды и проверял браузер.

Усечённые ответы и варианты с выдуманными API, obsolete model ID, неверным путём
binding, дублированным PowerShell common parameter и неверным mock DOM API
отклонялись или исправлялись авторами по фактическому выводу. В итоговую проверку
не засчитывались предложенные, но не выполненные моделью тесты. На проверке
оркестратора дополнительно найдено принятие пустого config через DTO defaults;
DeepSeek исправил требование точного набора ключей, добавлены регрессионные случаи.

Прямые DeepSeek/Gemini/OpenAI приняты **офлайн**. Настоящих прямых ключей для
live-генерации здесь не было; успешная генерация этими сервисами не заявляется.
Metadata GET проверяет доступность ключа/модели, но не гарантирует генерацию,
качество анализа, региональную доступность или отсутствие списаний на аккаунте.
Денежный потолок прямых сервисов приложение не подтверждает.

Публикация в GitHub не выполнялась. DPAPI рассчитан на локальный Windows-профиль;
пользовательская изоляция и production vault для сайта остаются будущей задачей.
