# S0-05 — краткая приёмка

14 октября 2026. Детектор CrashLoopBackOff и очищенный контекст реализованы.

- `detect` работает без БД/LLM на 10 synthetic-сценариях: 6 инцидентов,
  4 отрицательных случая. Тот же результат проверен на 10 сохранённых
  захватах local-kind из S0-03.
- Дедупликация по владельцу/контейнеру/окну, init-контейнеры, лимиты и хеш
  контекста проверены. Канарейки отсутствуют в Incident, Context, JSON и CLI;
  инструкции из логов остаются помеченными недоверенными данными.
- Прогон с PostgreSQL: **259 passed, 20 skipped**. Пропущены 19 live-kind
  тестов и 1 Windows symlink. 18 проверок БД выполнены.
- Ruff, mypy, обе границы import-linter, 24 схемы и package assets прошли.
- Gitleaks staged/history прошёл; единственное исключение — явно невалидная
  PEM-фикстура в тесте redaction, отмеченная на конкретной строке.
- DeepSeek подготовил модули, Gemini — отдельные тесты и ревью. После проверки
  исправлена потеря переноса строки между log evidence; регрессия покрыта.
  Консервативное маскирование connection string и отказ при коллизии ключей
  сохранены как заданное поведение. Распознавание секретов эвристическое.

Ограничение среды: у существующего kind контейнера Docker сохраняет
HostConfig.PortBindings, но NetworkSettings.Ports для API пуст. TLS CA,
регистрация и принадлежность контейнера подтверждены. Обновление токена и
перезапуск только этого контейнера не восстановили публикацию порта.
Живая проверка S0-05 не выполнена. PostgreSQL доступен; данные кластера сохранены.
