# UI12 — загрузка, устаревшие данные и сообщения сервисов

17 октября 2026. Небольшая доработка интерфейса после UI11. Код подготовлен
DeepSeek, поведенческие тесты — Gemini через реальный OpenRouter. Оркестратор
проверял ответы, применял точные замены, запускал тесты и проверял браузер.
Backend/API, ключи, модели приложения и профили исполнения не менялись.

Поведение:

- До подтверждённого пустого ответа реестра экран не предлагает добавить первый
  проект. Загрузка, отсутствие подтверждённых данных и устаревший список различаются.
- При ошибке обновления сохраняются предыдущие карточки с явной отметкой.
  Новые проверки и удаление блокируются; чтение истории остаётся доступным.
  Поиск, перерисовка и смена согласия не обходят блокировку. Успешное чтение
  восстанавливает доступность с учётом running/submitted/consent.
- Неопределённая попытка запуска не разрешается повторно после восстановления
  реестра. Подсказка и disabled кнопки открытого runner обновляются совместно.
- Учитывается только последний запрос реестра; поздние ответы не заменяют свежие
  данные. Некорректный ответ без массива projects сохраняет предыдущий список.
- Ошибки кластерного аудита отделены от ошибок операций. На странице проектов
  это нейтральное scoped-сообщение, в остальных разделах — заметное предупреждение.
  Смена раздела или успешный refresh не стирает ошибки POST/операций. Ошибки
  обзора, включая отказ сессии, показываются отдельно и не маскируются под аудит.

Проверено:

- `node --test tests/ui/dashboard-flow.test.cjs`: **12 passed**. Пять прежних
  сценариев UI11 и семь новых: initial loading/empty/failure, stale карточки и
  блокировки, восстановление реестра в открытой форме, сохранение операционной
  ошибки при предупреждении аудита, отказ сессии/восстановление обзора, порядок
  пересекающихся успешных ответов, некорректное тело ответа.
- Выбранные HTTP safety tests: **12 passed, 75 deselected**,
  `.local/ui12-http-tests.xml`: static CSP/path bounds, сессия, Origin, общий job
  lock, локальные регистрация/проверка/отчёт. Новых backend-функций не добавлялось.
- Браузер: список семи проектов появляется независимо от обзора сервисов;
  при недоступном PostgreSQL нейтральное сообщение видно на странице проектов,
  предупреждение сохраняется при переходе в «Кластер и демо».
  Скриншот: `.local/dashboard/screenshots/ui12-project-status.png`.
- `node --check` и `git diff --check` прошли. Wheel собран из sdist offline
  в `.local/ui12-dist`; HTML/CSS/JS сверены с рабочими исходниками.
- Ответы моделей проверялись до применения. Первый вариант DeepSeek отклонён
  из-за очистки ошибок операций и неполных gates; исправления запрошены автору.
  Несовпадающие замены не применялись. Ошибки fixture Gemini возвращены автору;
  некорректная JSON-обёртка последнего ответа не использовалась: из неё строго
  JSON-декодирован готовый replacement для заранее определённого последнего теста,
  без ручного изменения сгенерированного кода. Условные пропуски asserts заменены
  автором на обязательные проверки реальных DOM-элементов.
  Материалы находятся вне Git в `work/agent-tasks/ui12`.

Во время визуальной проверки новые проверки проектов, Docker и runtime AI не
запускались. Платные вызовы относились к помощникам разработки. Кластер, сервисы,
kill switch, данные и F06 не изменялись. DOM mock не заменяет проверку браузером;
сетевые/ошибочные сценарии проверены offline, без повреждения реального реестра.
