# Приёмка UI17: контекст и проверка предложений AI

17 октября 2026. Реализованы пять согласованных улучшений: локальная карта,
подбор связанных файлов, тестирование предложения до/после, diff с новым тестом
и небольшой контрольный набор качества. Продуктовый код получен от DeepSeek,
тесты и независимое статическое ревью — от Gemini через OpenRouter. Оркестратор
проверял ответы, применял точные изменения, выполнял команды и оформлял документы.
Встроенные Codex-агенты для реализации не использовались. GitHub не обновлялся.

## Реальная локальная проверка

В браузере открывались карта и подбор контекста проекта «Демо · AI-анализ кода».
Один файл average.py — открытый учебный пример с ошибкой range(len(values) + 1).
Карта показала функцию, подбор корректно сообщил об отсутствии связанных файлов.
Никакие произвольные пользовательские исходники в QA не отправлялись.

Первое предложение для старого предпросмотра 815117a1-3be5-4017-872d-a1672c72d89c
завершилось failed; подробная причина не сохранена старой версией. Отдельный
контрольный разбор c522730c-0982-4d9c-84ae-ecabd74f55c7 не подтвердился за 30 секунд.
Эти записи сохранены, автоматического повтора не было. Затем отдельный новый
предпросмотр 83f0cc3b-cf7f-4a03-9b3e-765da9ab5e1d прошёл реальный разбор и запрос
исправления с отдельными согласиями. Модель предложила единственную правку
range(len(values)) и три pytest-теста. Ответ и diff показаны в браузере.
Данные экспортной ссылки сохранены локально; **git apply --check** на учебной
папке проходит, без применения. Событие скачивания в IAB не было подтверждено;
проверен payload ссылки, а не завершение системного диалога скачивания.

Docker-проверка обеих копий сохранена как **inconclusive**: runner_unavailable,
execution_scope=not_started. Запуски 7557b5aa-7d3e-49e6-b037-22269fe3cc9b
и dd964c09-1a70-4430-a0fa-ed2b7c1cf96e содержат разные проверенные хеши снимков.
UI показывает невозможность сделать вывод и открывает оба отчёта; в отчёте
указана недоступность Docker/подготовленного образа. Фактического выполнения
сгенерированного теста и подтверждения исправления в Docker в этой приёмке нет.
Сценарий reproduced проверен offline с полными согласованными RunResult,
что не заменяет живой Docker-прогон. Исходный average.py не изменялся.

Реальная оценка 0ed50238-9529-4b44-ad18-bdfaa5534448 завершена: ответы на 3/3
синтетических примера, TP=1, FP=1, FN=0, precision=0.5, recall=1.0.
На обоих корректных примерах замечаний нет, включая инструкцию в комментарии.
Лишнее замечание относится к условному делению на ноль после исправления цикла.
Это оценка по учебной разметке и пересечению строк, не общая точность модели.

## Исправления по результатам приёмки

Проверки выявили реальные ошибки: разрешение импортов Python и JS, профили
снимков, общий индекс истории оценки, предварительную проверку verification,
формат данных lab/evaluation в UI и чтение dict результата проверки сервером.
Они исправлены автором кода. Ошибочные mock-форматы тестов исправлены Gemini.
Неполные ответы моделей, неверные API-предположения и предложенные изменения
без фактического основания не применялись. Ревью pure-модулей/worker и host
принято без замечаний до браузерной проверки; последующее ревью не заметило
часть несовпадений DTO. Поэтому выводы ревью не подменяют реальные проверки.
Последнее замечание Gemini о generic failure отклонено: default unknown задан
явно; внутренний сбой нельзя объявлять ошибкой связи без доказательств.
