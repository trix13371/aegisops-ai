# F03 — сравнение с размеченной причиной и исходом

15 октября 2026. Следующий локальный срез eval (п. 4.6 плана до MVP).
Добавлены необязательные confirmed_cause/incident_outcome/reference в отзыв,
команда `feedback quality`, чистый вычислитель и ограниченный SQL-reader.
Миграция `0003_feedback_labels` применена к локальной PostgreSQL, прежние
отзывы и audit_runs сохранены. Обратная совместимость без новых полей проверена.

Отчёт сравнивает диагноз выбранного запуска с локальной разметкой. Повторные
запуски/reviewer одного incident ID дают один case. Конфликты причин/исходов,
неразмеченные случаи, abstention и обрезанные группы учитываются отдельно;
неполная группа не даёт match/mismatch. Provider/model_name/prediction_kind
различают fixtures, fallback, ответ модели и неизвестное происхождение.

Проверено:

- Полный pytest с PostgreSQL и `AEGISOPS_KIND_LIVE=1`: **587 passed,
  1 skipped, 2 deselected**, включая 20 живых kind-тестов. Пропущен Windows
  symlink; два платных API-теста исключены по умолчанию.
- 41 новый unit/integration/safety-кейс: разметка требует reference,
  unknown-причина отвергается, наследование старого формата, match/mismatch,
  неопределённые/множественные диагнозы, дедупликация, выбор последнего запуска,
  конфликт и усечение, происхождение диагноза, run/origin/ID/hash привязки,
  подмена счётчиков и недопустимые лимиты, отсутствие частичного CLI-вывода.
- Реальная PostgreSQL проверяет текущие листья после исправления, полную и
  обрезанную группу, фильтрацию origin, CLI и ограничения новых колонок.
  Отдельный тест делает конкурентную правку во время чтения: отчёт остаётся
  на прежнем согласованном snapshot; следующее чтение видит новую оценку.
  В транзакции действительно `transaction_read_only=on`.
- Ruff/format, mypy (58 файлов), 8 контрактов import-linter, 33 JSON Schema
  с golden-примерами, package assets, Alembic check и doctor local-kind прошли.
  SQLAlchemy metadata совпадает с мигрированной PostgreSQL.
- Pre-commit и gitleaks staged прошли без находок секретов.
- [Безопасный пример отчёта](docs/verification/f03-labels/summary.json) построен
  на автоматической учебной разметке и явно не является измерением качества SRE/LLM.

DeepSeek подготовил вычисление одного case; исправлены обращения к фактическому
DTO и типы UUID перед применением. Первый большой ответ был неполным и не
применялся. Gemini независимо просмотрел сравнение/SQL; предложенные проверки
дедупликации, усечения и конфликтов выполнены локально. Предположения ревью
не принимались за доказанные дефекты без воспроизведения.
Телеметрия и отзывы внешним моделям не отправлялись; платного анализа инцидентов
в приёмке нет. Удалённый CI не запускался.

Это сравнение с утверждениями локального reviewer, не независимая проверка
постмортема. Нет оценённого исторического golden-набора, статистического quality
gate, Shadow, MTTR или подтверждения, что рекомендация повлияла на исход.
Существующие incident ID имеют пятиминутное окно; их нельзя автоматически
считать независимыми инцидентами. Уровень остаётся L0.
Решение: [ADR-012](docs/decisions/ADR-012-labelled-comparison.md).
