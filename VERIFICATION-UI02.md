# UI02 — добавление локальных проектов

Завершено 16 октября 2026. Доступен раздел «Мои проекты»: имя, абсолютный путь,
регистрация, проверка папки, история, отчёт и удаление регистрации без удаления
файлов проекта. Доступен также источник «Добавленный проект» на обзоре.

Профиль local-static-v1 проверяет Python/JSON/YAML/TOML и несколько контейнерных
настроек. JS/TS определяется по структуре. Никакой проектный код, тесты, сборка
или установка пакетов не выполняются; сетевых/LLM вызовов из scanner нет.
Положительный результат не подтверждает работоспособность или безопасность ПО.

Проверено:

- Общий прогон PostgreSQL/kind/OPA: **971 passed, 3 skipped, 2 deselected**.
  Существующие Windows symlink/POSIX-mode пропуски и новый symlink-тест без
  привилегии Windows; платные LLM smoke исключены. XML — `.local/project-tests.xml`.
- После четырёх дополнительных регрессий (кавычки пути, NaN JSON, общий байтовый
  бюджет и противоречивый partial-отчёт) финальная выборка project/UI safety:
  **53 passed, 1 skipped**. Повтор всего live-suite после этих правок не запускался.
- Реальный синтаксический разбор, duplicate keys, несколько YAML-документов,
  privileged/host namespace/image/limits warnings. Невалидные исходники не
  исполняются; canary-файлы исключений не открываются, source text не сохраняется.
- Oversized файлы, YAML aliases, отсутствие поддержанных файлов и суммарный
  byte budget дают partial. Перечисление ограничено; ссылки не обходятся.
- Путь относительный, URL/UNC, лишние command/provider поля, дубликат папки,
  замена root-directory, повреждённый реестр/отчёт отвергаются. Partial нельзя
  структурно переобозначить как passed. История хранит 20 последних ссылок.
- Новые API требуют ту же сессию/Host/Origin. Статический worker не вызывает
  subprocess. Удаление активного проекта во время проверки запрещено.
- В браузере добавлена настоящая папка AegisOps AI, запущена проверка и открыт
  отчёт: **542 файла замечено, 457 проверено, 125 пропусков файлов/каталогов,
  0 замечаний**, статус «Форматы проверены». Число пропусков включает каталоги,
  поэтому не равно разности файловых счётчиков.
- После остановки/старта UI host проект и отчёт доступны в истории; JavaScript
  ошибок нет. В интерфейсе оставлена карточка AegisOps AI. Отчёт относится к
  данным запуска, не фиксирует Git revision и не заменяет автоматические тесты.
- Ruff/format, mypy (**96 source-файлов**), **17 import-контрактов**, 57 прежних
  schemas и assets прошли. Новых зависимостей и миграций нет. Новые project DTO —
  внутренний local-operator формат, не часть общих incident schemas S0.
- Wheel построен из sdist; registry/report/session/ключи не входят в пакет.
  Операторский launcher по-прежнему используется из checkout.
- F06 после общего прогона закрепляет **1275 строк audit_runs**, verified,
  missing/modified/unanchored — 0. Новые project reports хранятся отдельно и
  **не входят** в этот подписанный аудит.

Ограничения: один trusted OS user/filesystem, локальный реестр без подписи,
эвристический список исключений и выбранные проверки вместо SAST/полного schema
validation. Временной бюджет кооперативный; принудительного прерывания парсера
нет. Source snapshot не фиксируется, orphan/старые отчёты не удаляются сами.
Задача не подключает произвольный Kubernetes или удалённый Git-репозиторий.
Решение: [ADR-020](docs/decisions/ADR-020-local-project-registry.md).
