# UI13 — файлы и тесты из одного снимка

17 октября 2026. Код приложения и операторов подготовлен DeepSeek через
OpenRouter; тесты и независимое ревью — Gemini через OpenRouter. Оркестратор
задавал контракты, проверял ответы, применял точные замены, запускал проверки,
оформлял документацию и проверял браузер. Встроенные Codex-агенты не применялись.

## Поведение

- Новый режим «Файлы + тесты»: выбор языка, прежнего подготовленного окружения,
  отдельное согласие Docker; один captured Snapshot для static и runner.
- Исходная папка после копирования не перечитывается для этих проверок.
  Статический сканер работает по проверенному архиву в новой временной папке,
  код исполняется только прежним изолированным контейнерным runner.
- Общая история и отчёт сохраняют ссылки и хеши составляющих. Чтение повторно
  проверяет проект, профиль, окружение, временной порядок и итог из источников.
  Старые DTO и исторические сводки сохраняют сериализацию и ограничения.
- При недоступном Docker статический результат доступен, общий итог неполный.
  Ошибка подготовки/разбора снимка не запускает код. Неизвестный результат,
  partial, усечённый вывод и неподтверждённая очистка не считаются успехом.
  Маркеры O_EXCL запрещают повторное исполнение той же попытки.
- API использует существующий loopback host, session, Origin и общий job lock.
  GET истории/отчёта не запускает проверки или модель. AI автоматически не вызывается.

  замечаниях static и успешных тестах, счётчики и отбрасывание устаревшего ответа.

В процессе приёмки исправления возвращались авторам: выдуманные поля SnapshotInfo
и UI DTO, неверный consent mapping, потеря причины недоступности runner,
неверные fixtures/пути и DOM selectors. Незавершённый ответ Gemini на большой
первоначальный тестовый запрос отклонён; задача разделена. Несовпадающие замены
не применялись. Форматирование и удаление пробелов выполнены механически.
Промежуточные ответы находятся вне Git в `work/agent-tasks/ui13`.

Новый снимок ограничен профилем и создаётся последовательно, не атомарно для всех
файлов. Подтверждается общая входная копия, а не полное покрытие, соответствие
текущей папке или безопасность проекта. История не подписана, не является F06.
Проверка ошибки Docker выполнена offline с подменой границы, без остановки
реального двигателя. Runtime AI, кластерные действия, политики и kill switch
в этой приёмке не вызывались и не изменялись.
