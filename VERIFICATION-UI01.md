# UI01 — локальная панель AegisOps

Проверено 15 октября 2026. Визуальная оболочка текущего L0, без смены политики
и без платных вызовов модели. Запуск — `Start-AegisOps.cmd` двойным щелчком.

Сделано: адаптивный русский интерфейс с обзором, историей до 25 записей, поиском,
фильтром источника, подробным разбором инцидента и состоянием сервисов. Локальный
kind запускается через отдельные процессы F09; три учебных сценария используют
существующий pipeline. Фоновые проверки показывают прогресс и ссылку на аудит.
Внизу страницы можно завершить idle-приложение; активная задача не прерывается.

Проверки:

- **949 passed, 2 skipped, 2 deselected** в общем прогоне с настоящими PostgreSQL,
  kind и mTLS OPA. Windows symlink/POSIX mode пропущены как раньше; платные тесты
  исключены. XML — игнорируемый `.local/dashboard-tests.xml`.
- **27 новых safety-тестов**: текущая сессия, bootstrap/cookie, Host против
  rebinding, Origin/CSRF, ограничения JSON/размера/сценариев, duplicate keys,
  запрет произвольных команд/провайдера, один job, безопасные ошибки без retry,
  фильтрация environment, остановка idle UI и отказ остановить активный job.
  Эти тесты также повторно прошли после добавления socket timeout и сообщения
  об ошибке запуска без консоли.
- В настоящем браузере: чтение аудита и карточки инцидента; local-kind и OOM
  сценарий; фильтр, поиск и навигация; остановка через интерфейс; новый запуск
  `Start-AegisOps.cmd` через pythonw. Ошибок JavaScript в последней сессии нет.
- Последний запуск из финального интерфейса: **10 наблюдений, 6 инцидентов,
  blocked**, ссылки на шесть сохранённых записей. Kill switch остался включён,
  generation 13; исполнений и внешних вызовов модели — 0. Блокировка явно показана.
- Макет проверен на ширине 390px и 1366px; горизонтальное переполнение находится
  внутри таблицы, не всей страницы. Drawer поддерживает закрытие кнопкой/overlay/Escape,
  удержание клавиатурного фокуса и возврат после закрытия. На узком экране
  меню компактное, карточки и панель сервисов перестраиваются в колонку.
- Невалидные старые тестовые строки БД пропускаются с видимым предупреждением,
  не превращаются в пустые «здоровые» проверки. История показывает реальные
  данные, включая результаты автоматических тестов этой же локальной БД.
- Listener подтверждён только на `127.0.0.1:8765`. API-ключей в UI нет. Host/Origin,
  HttpOnly/SameSite cookie, no-store, CSP, запрет framing; сырые context/provider
  metadata не входят в проекцию. Весь API-текст выводится через textContent.
- Ruff/format, mypy (**92 source-файла**), **16 import-контрактов**, 57 schemas и
  package assets прошли. Новые зависимости и миграции не добавлены.
- Wheel построен из sdist; HTML/CSS/JS/SVG присутствуют, PEM/DPAPI/key и `.local`
  отсутствуют. Операторский launcher запускается из checkout, не из wheel.

Ограничения: stdlib HTTP host — локальный инструмент одного доверенного
OS-пользователя, без публичного доступа, аккаунтов или production deployment.
Статусы здоровья кешируются до 15 секунд и обновляются кнопкой; регистрация
collector не означает live connectivity. Job state в памяти не заменяет durable
workflow; после сбоя нужны аудит и F09 spool, автоматического reconcile нет.
Это работающий интерфейс прототипа, не завершённый Этап 1.
