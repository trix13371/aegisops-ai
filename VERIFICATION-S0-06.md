# S0-06 — краткая приёмка

15 октября 2026. Ограниченный LLM-анализ, рекомендации и fallback реализованы.

- `analyze` по умолчанию бесплатно обрабатывает 10 сценариев и выдаёт 6
  учебных результатов, без fallback и исполнения. `--llm none` демонстрирует
  unknown/escalate. Доступны OpenRouter и локальный OpenAI-совместимый HTTP API.
- Два Draft за один запрос; максимум одна повторная попытка, общий бюджет,
  лимиты входа/выхода/времени. Только evidence из переданного контекста,
  каталог/параметры/текущий target; поля безопасности и ID назначает приложение.
  Подтверждены отказ от tools, неизвестных действий, лишних параметров,
  вымышленных ссылок, чужого workload и модельных полей безопасности.
- Прогон с PostgreSQL: **332 passed, 20 skipped, 2 deselected**. Пропущены
  19 live-kind тестов и 1 Windows symlink; 2 платных теста исключены по умолчанию.
  Среди выполненных — 73 новые проверки engine/transport/safety/local HTTP.
- Отдельно **2 live-теста OpenRouter прошли**: OOM и fake-secret canary,
  с валидным структурированным ответом без fallback. Настоящий loopback
  HTTP-сервер дополнительно проверил тело запроса: без tools и канарейки.
  Это smoke-проверки, не оценка качества модели.
- Ruff, format, mypy, 3 контракта import-linter, 25 схем и package assets прошли.
  Миграция БД без дрейфа; `doctor` зелёный. Платные тесты в CI не включены.
- Wheel собран и установлен в отдельную временную папку: все 6 offline-анализов
  прошли на упакованных assets. pip-audit не нашёл известных уязвимостей
  зависимостей; локальный пакет проекта не имеет записи для проверки на PyPI.
- Pre-commit прошёл, gitleaks не нашёл секретов в staged-файлах и истории Git.
- DeepSeek подготовил части реализации, Gemini — независимые тесты и ревью.
  После локальной проверки исправлены DTO/импорты тестов, обработка больших
  контекстов и подключение через настроенный CONNECT proxy. Три замечания
  ревью не подтвердились: лишние параметры отвергает каталог, HTTP-ответы
  закрываются в finally, пустые evidence отвергает DTO. Поведение покрыто тестами.

Сырые промпты/ответы и ключи приложение не записывает. Ошибка/таймаут первой
попытки может сделать фактический usage неполным — это явно отражено метаданными.
Redaction эвристическая; DNS управляется ОС. Локальный kind по-прежнему не
публикует API-порт (см. S0-05), поэтому его живой анализ не проверен.

Политика, dry-run, статусы полного запуска и запись в AuditStore относятся
к S0-07. Исполнителя нет, уровень L0; это не готовность к production.
