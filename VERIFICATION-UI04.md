# UI04 — нейросетевой разбор сводки проекта

Завершено 16 октября 2026. В отчёте доступен отдельный платный разбор сводки
через OpenRouter. Состав JSON показан до согласия; исходники/имена/пути/значения
не передаются. Ответ с приоритетами и ручными следующими шагами сохраняется
локально и не изменяет статический отчёт или файлы проекта.

Проверено:

  `.local/ui04-tests.xml`. Пропуски — Windows symlink/POSIX mode. Общий live
  PostgreSQL/kind/OPA suite в этой задаче не запускался.

Ограничения: модель видит только категории и счётчики статического профиля,
не анализирует исходники и не запускает тесты. Рекомендации могут быть ошибочны;
действия выполняет человек. Это не гарантия безопасности/работоспособности.
Одна попытка на отчёт, неопределённый запрос не повторяется; исправив подключение,
оператор может создать новый статический отчёт для новой осознанной попытки.
История не подписана; trusted user/filesystem и прежние ограничения сохраняются.
